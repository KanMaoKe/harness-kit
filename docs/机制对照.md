# 能力与边界

harness-kit 为项目准备规则、任务上下文、状态、记忆与技能文件，并提供维护这些文件的命令行工具。默认完整档适合复杂项目，也提供精简档。下表区分程序行为与需要用户、AI 或宿主执行的约定。

## 工具已实现的能力

| 能力 | 实现位置 | 实际行为 |
|---|---|---|
| 项目识别 | `kit/core.py` | 根据项目文件与目录选择模板类型 |
| 初始化 | `kit/init_harness.py` | 补齐模板，保留已有正文；显式覆盖仅针对项目约定 |
| 标准入口 | `--agents-md` / `AGENTS.snippet.md` | 可选创建或更新托管入口片段，保留其他项目指令 |
| 任务恢复 | `kit/resume.py` | 校验并读取当前任务状态，输出下一步与优先读取路径 |
| 结构体检 | `kit/doctor.py` | 检查核心文件、占位内容、任务状态、可选记忆长度与版本 |
| 项目总览 | `kit/status.py` | 扫描指定深度内可识别的子项目并列出问题数 |
| 文件同步 | `kit/sync.py` | 补齐缺件并更新版本元数据，不迁移已有正文 |
| 目录静音 | `kit/mute.py` | 维护会话提示的目录静音名单 |
| 可选安装 | `install.py` | 安装代码与技能到指定位置，默认不注册 hook |
| 可选会话提示 | `kit/hook_session_start.py` | 启用并接入兼容宿主后，输出初始化询问的上下文 |

## 模板提供的约定

| 文件 | 目的 | 执行者 |
|---|---|---|
| `PROJECT.md` | 稳定的项目目标、架构与协作约定 | 用户与 AI 填写、维护及遵守 |
| `STATE.json` | 当前任务目标、验收、验证、阻塞及下一步 | 用户或 AI 按阶段更新 |
| `TASKS.md` | 根据任务选择相关上下文与工具 | AI 判断，宿主提供读取和工具能力 |
| `MEMORY.md` | 整理稳定事实与长期决策 | 用户或 AI 蒸馏与更新 |
| `CHECKPOINTS.md` | 记录决策、未完成事项和接续位置 | 用户或 AI 在关键阶段更新 |
| `NARRATIVE.md` | 记录重要转折与决策理由 | 用户或 AI 根据需要整理 |
| 日期日志 | 保存当日工作记录 | 初始化创建当天文件，后续由用户或 AI 维护 |
| `skills/README.md` | 定义技能格式、拆分与验收方式 | 用户或 AI 编写具体技能 |

检查点轮次、按需读取与验收清单属于文本约定，不表示后台自动执行。认知原语是可选的技能组织方法。完整档保留记忆与技能指南；精简档只生成项目规则、任务协作说明、状态和入口片段。工具不会自动加载这些文件。

## 需要额外接入的能力

- 自动发现并读取项目指令，需要客户端入口或用户明确指定。
- 每轮上下文注入、工具暴露和执行编排，需要宿主或独立运行时支持。
- 检索可使用宿主提供的文件搜索；本项目没有内置 BM25 或向量库。
- 实际成果验收需要运行项目测试或其他适用检查；文件检查不替代成果验证。
- 会话 hook 使用特定事件及 JSON 格式，其他客户端需要适配并实际验证。

当前默认目录、兼容行为、命令参数和安装方式见 [README](../README.md)。
